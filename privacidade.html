Política de Privacidade

Atualizada em 17 de novembro de 2026.

1. Quem é o responsável

A SatoTech, de Minoru Sato, é responsável pelo tratamento dos dados pessoais coletados por meio deste site. Para qualquer assunto relacionado a esta política, escreva para satotech.jp@gmail.com.

2. Quais dados coletamos

Coletamos apenas os dados que você mesmo nos envia ao entrar em contato, como nome, telefone ou WhatsApp, e-mail e o conteúdo da sua mensagem. Este site não usa ferramentas de rastreamento publicitário nem coleta dados de navegação para fins de marketing.

3. Para que usamos os seus dados

Usamos os dados somente para responder ao seu contato, elaborar propostas e prestar os serviços contratados. Não usamos os seus dados para nenhuma outra finalidade sem o seu consentimento.

4. Compartilhamento

Não vendemos nem compartilhamos os seus dados pessoais com terceiros para fins de marketing. O compartilhamento só acontece quando exigido por lei ou por ordem de autoridade competente.

5. Sistemas de demonstração

As demonstrações apresentadas pela SatoTech funcionam com dados fictícios, criados apenas para exibição. Não insira dados pessoais reais em ambientes de demonstração.

6. Os seus direitos

Você pode solicitar o acesso, a correção ou a exclusão dos seus dados pessoais a qualquer momento, pelo e-mail satotech.jp@gmail.com. Respondemos às solicitações no menor prazo possível.

7. Alterações desta política

Se esta política mudar, a versão atualizada será publicada nesta mesma página, com a data de atualização.
